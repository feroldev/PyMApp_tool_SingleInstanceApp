# Security Policy

## Supported Versions

Currently supported:

| Version | Supported |
| ------- | --------- |
| 1.6.x   | Yes       |

## Reporting a Vulnerability

If you discover a security issue, please open a private security report or contact the maintainer.

Please include:

* Affected version.
* Steps to reproduce.
* Potential impact.
* Proposed mitigation if available.

Reports will be reviewed as quickly as possible.
